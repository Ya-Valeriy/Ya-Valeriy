# Содержимое репозитория

Здесь вы найдёте мои учебные и демонстрационные артефакты, доказывающие навыки ручного тестирования:

- **`test-design/`** — чек-листы, тест-кейсы, майнд-карты для сценариев WMS (приёмка, сборка, отгрузка).  
- **`bug-reports/`** — примеры оформления багов с приоритетами и шагами воспроизведения.  
- **`sql-queries/`** — коллекция запросов для проверки данных (складские остатки, статусы заказов).  
- **`api-testing/`** — коллекция Postman с тестами REST API (создание/изменение заявок).  
- **`automation-learning/`** — (в планах) базовые скрипты на Python + Selenium для ознакомления.
