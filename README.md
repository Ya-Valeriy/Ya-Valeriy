# Содержимое репозитория

Здесь вы найдёте мои учебные и демонстрационные артефакты, доказывающие навыки ручного тестирования:

1. Artifacts_manual_testing
Описание: Артефакты ручного тестирования: тест-кейсы, баг-репорты, SQL-запросы, API-тесты (Postman), анализ требований (User Story, RTM).

2. VELOSKLAD_PYTHON_PLAYWRIGHT_PYTEST_POM
Описание: Проект автоматизированного тестирования для сайта «Велосклад». Использует Playwright для автоматизации браузеров, pytest как фреймворк тестирования и Allure для генерации отчётов.

3. Velosklad_Selenium_Webdriver
Описание: Проект тестирования веб-приложения с использованием Python, pytest и Selenium WebDriver. Структура включает Page Object Model для страниц каталога, поиска, товара и корзины.

4. Velosklad
Описание: Автоматизированные тесты для интернет-магазина велотранспорта Velosklad.ru. Код написан на Python с использованием библиотек автоматизации (Selenium WebDriver).

5. urait-tests
Описание: Последовательный интеграционный сценарий автоматизированного тестирования для главной страницы и основного навигационного меню. Включает Smoke-тестирование и регрессионное тестирование навигации.

6. BPMN_UML_ERD
Описание: Моделирование бизнес-процессов (BPMN), архитектуры микросервисов (UML) и структуры баз данных (ERD) для логистических и e-commerce платформ.
