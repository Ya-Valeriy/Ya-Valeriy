 - Моделирование бизнес-процессов (BPMN), архитектуры микросервисов (UML) и структуры БД (ERD) для логистических и e-commerce платформ.

 - Артефакты ручного тестирования: тест-кейсы, баг-репорты, SQL-запросы, API-тесты (Postman), анализ требований (User Story, RTM).

https://github.com/Ya-Valeriy/velosklad-playwright-pytest
 - Проект автоматизированного тестирования для сайта Велосклад. Playwright — фреймворк для автоматизации браузеров pytest — фреймворк для тестирования на Python Allure — инструмент для генерации наглядных отчётов POM (Page Object Model) — архитектурный паттерн для организации кода.

https://github.com/Ya-Valeriy/velosklad-pytest-selenium
 - Это проект тестирования веб-приложения с использованием Python, pytest и Selenium. Структура включает page object model, каталога, поиска, товара и корзины. Тесты расположены в tests/, страницы в pages/, используется Allure для отчетности. Проект предназначен для регрессионного тестирования функциональности интернет-магазина.

https://github.com/Ya-Valeriy/velosklad-webdriver-logging
 - В репозитории Ya-Valeriy/Velosklad содержатся автоматизированные тесты для интернет-магазина велотранспорта Velosklad.ru. Код написан на Python с использованием библиотек автоматизации (Selenium WebDriver).

https://github.com/Ya-Valeriy/urait-tests
 - Последовательный интеграционный сценарий автоматизированного тестирования для главной страницы и основного навигационного меню. Смок-тестирование (Smoke Testing) и регрессионное тестирование навигации. Цель: Быстро убедиться, что основные «двери» (разделы) сайта открываются, а ссылки не ведут на пустые страницы или ошибку.
